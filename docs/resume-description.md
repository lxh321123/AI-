# 简历项目描述

项目名：AI 任务调度与结果管理平台

技术栈：Spring Boot、MySQL、Redis、RabbitMQ、XXL-Job、Docker、Nginx、MyBatis-Plus

项目描述：

面向企业内部 AI 分析场景设计并实现任务调度与结果管理平台，支持用户提交文本摘要、风险识别、问答生成等 AI 任务，通过 RabbitMQ 异步处理任务，并提供任务状态查询、结果查询、失败重试和超时补偿能力。项目重点解决 AI 任务耗时不稳定、重复提交、重复消费、状态一致性和结果查询性能等后端工程问题。

项目亮点：

- 设计任务创建、异步处理、结果落库、状态查询、失败重试的完整业务闭环，使用 RabbitMQ 解耦接口请求与任务执行，提升接口响应速度和系统吞吐能力。
- 基于 `bizId`、Redis 分布式锁和 MySQL 唯一索引实现任务创建幂等，避免用户重复提交导致重复任务。
- 在消费端使用 Redis 处理锁、任务状态判断和结果表唯一索引实现重复消费防护，保证同一任务结果只写入一次。
- 使用 Redis 缓存任务详情和任务结果，采用 Cache Aside 策略，并在任务状态变化后主动清理缓存，降低数据库查询压力。
- 接入 XXL-Job 实现超时任务扫描和失败任务自动重试，并通过统一异常处理、任务日志和 Docker Compose 提升项目可维护性和可部署性。

面试一句话：

这个项目本质上是一个 AI 场景下的异步任务平台，我主要用 Spring Boot、MySQL、Redis、RabbitMQ 和 XXL-Job 实现了任务提交、异步消费、状态流转、结果管理、幂等控制和失败补偿。
